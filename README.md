# 🎮 Rèptor - Joc Trivial Web

## 📌 Descripció
Aquest projecte consisteix en el desenvolupament d’un joc web tipus **quiz**, creat amb **HTML, CSS i JavaScript** i gestionat amb **GitHub**.

L’usuari respon preguntes amb diverses opcions i, al final de la partida, pot veure els seus resultats i estadístiques, podent tornar a jugar si així ho desitja.

---

## 🎯 Objectius del projecte

- Desenvolupar una aplicació web funcional
- Aplicar coneixements de frontend
- Treballar amb control de versions (GitHub)
- Crear una experiència interactiva per l’usuari

---

## 🧩 Funcionalitats

- 🔤 Introducció del nom (obligatori)
- 🎲 Selecció del tipus de preguntes:
  - Aleatori
  - Manual
- ❓ Sistema de preguntes amb opcions múltiples
- ✅ Validació de respostes
- 📊 Pantalla de resultats
- 📈 Estadístiques globals
- 🔄 Opció de tornar a jugar
- ⏱️ Temporitzador per pregunta
